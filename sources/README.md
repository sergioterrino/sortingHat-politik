# Fuentes electorales

Esta carpeta contiene documentos primarios descargados de páginas oficiales.
No se deben convertir automáticamente en posiciones políticas sin revisión humana,
cita de página y comprobación de la elección a la que pertenecen.

## Descargadas

- `pp_programa_23j_2023.pdf`: programa del Partido Popular para las generales de 2023.
- `sumar_un_programa_para_ti_2023.pdf`: programa de Sumar para las generales de 2023.
- `podemos_programa_marco_28m_2023.pdf`: programa marco de Podemos para las municipales de 2023.
- `pnv_documentos_oficiales_2023.html`: página oficial de documentos del PNV; requiere seleccionar el documento electoral concreto.
- `pnv_programa_23j_2023.pdf`: programa oficial del PNV para las generales de 2023.
- `ehbildu_programa_2023.pdf`: programa oficial facilitado por EH Bildu.
- `bng_programa_generales_2023.pdf`: programa del BNG para las generales de 2023.
- `coalicion_canaria_programa_autonomicas_municipales_2023.pdf`: programa de Coalición Canaria para autonómicas y municipales de 2023.
- `frente_obrero_programa_2025.pdf`: programa oficial de Frente Obrero publicado en 2025.
- `pacma_programa_generales_2023.pdf`: programa de PACMA para las generales de 2023.
- `upn_programa_generales_2023.pdf`: programa de UPN para las generales de 2023.
- `teruel_existe_programa_autonomico_2023.pdf`: programa autonómico de Teruel Existe de 2023.
- `nueva_canarias_programa_2023.pdf`: programa electoral de Nueva Canarias de 2023.
